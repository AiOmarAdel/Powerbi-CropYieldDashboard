# 🌾 Crop Yield Dashboard

An interactive **Power BI Dashboard** designed to analyze crop yield and agricultural performance through interactive visualizations and key performance indicators.

## 📊 Dashboard Overview

The dashboard provides an interactive view of crop yield data, helping users explore agricultural performance across different crops, regions, seasons, and other available dimensions.

## 🎯 Objectives

* Analyze crop yield performance.
* Identify trends and patterns in agricultural production.
* Compare crop performance across different categories.
* Provide interactive filtering and data exploration.
* Present agricultural insights through clear and interactive visualizations.
